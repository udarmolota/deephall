Deephall's on-screen controls as laid out and tested on a Samsung S25 Ultra, kept here to become the
built-in default of the standalone app. controls.json is the launcher's layout format; icons/ holds
the images it names.

- storm_*.png: the StormDroid "Classic" icon pack by udarmolota, CC0 (see LICENSE-storm-icons.txt).
- deephall_*.png: cut from Mountaincore's own UI atlas (MIT, see the game's LICENSE) and turned into
  white glyphs so the launcher can tint them.
